# Hair-Loss Drug-Repurposing Reports

Outcomes from an automated "mini co-scientist" pipeline that hunts for
repurposable treatments in existing approved drugs, supplements, and
topicals. Two completed runs are published here:

- **[Male pattern hair loss (androgenetic alopecia)](aga-male-pattern-hair-loss/report.md)**
  — 3 rounds, 32 hypotheses. Top picks: clascoterone (topical), diazoxide,
  deferiprone, roflumilast, misoprostol.
- **[Diffuse unpatterned alopecia (DUPA)](dupa-diffuse-unpatterned-alopecia/report.md)**
  — 3 rounds, 44 hypotheses. Top picks: biomarker-gated micronutrient
  correction (ferritin/vitamin D), topical adenosine, a sequential
  androgen-axis program, TSH-gated levothyroxine, gated tofacitinib
  (areata-incognita rule-out).

Each folder has the full report as Markdown (`report.md`) and a
self-contained annotated HTML version (`report.html` — download and open in
a browser).

> **Disclaimer:** These reports are research-prioritization artifacts
> generated by an automated hypothesis-triage loop. They are **not medical
> advice**, and no candidate is endorsed for clinical use. All hypotheses
> require expert review and experimental validation.

## How these were produced

A multi-agent loop replicating the "AI co-scientist" pattern
(generate → peer-review → Elo tournament → evolve, repeated over 3 rounds),
grounded in PubMed literature, the ChEMBL approved-drug universe, and a
curated supplement list. Top candidates were cross-checked against
ClinicalTrials.gov (prior trials), OpenTargets (target–disease association),
and PubMed co-mention novelty before final ranking. A Harvard TxGNN
knowledge-graph model was run as an independent check on the AGA run (no
concordance signal; documented in that report's appendix).
